# Changelog

## 1.0.0 (2026-11-10)

First release:

- Connect a store to Stamps.com through the myZenCartZone connection service.
- Check addresses and get USPS rates.
- Buy, reprint and void labels.
- Track shipments.
- Schedule USPS pickups and create SCAN forms.
- See the Stamps.com balance before buying.
- Print a sample label to check alignment.
- U.S. destinations only.
- Notifiers for add-ons: allow an order, add form fields, change the Stamps.com
  request, and react to a bought or voided label (docs/CUSTOMIZING.md).
